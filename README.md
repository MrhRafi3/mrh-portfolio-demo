## Overview

This portfolio website showcases Mrh Rafi's personal identity, engineering philosophy, and mobile application projects. Completely rebuilt from the ground up as a lightweight, accessible, editorial single-page experience.

### Featured Projects
- **Clocky:** Horological utility Flutter app combining a glowing analog dial, digital readout, international timezone offsets, and circular lap stopwatch.
- **Expify Beta:** Personal expense and budget tracker mobile app built for Bangladeshi Taka (৳ BDT) with donut analytics and project meters.
- **NomNom:** Contemporary food ordering and restaurant discovery app with dish customizer sheets, feast boxes, and simulated live courier tracking.
- **Alchemy:** Interactive educational gamification app exploring elemental synthesis and discovery.
- **AEVIQUE:** Luxury mobile photo and portrait editing application.

## Tech Stack & Architecture

- **Core Framework:** React 19 (`react` & `react-dom` v19.2)
- **Build System:** Vite 8 (sub-200ms production builds)
- **Typography:** Anton (Display), Manrope (Body), Caveat (Script)
- **Styling:** Pure CSS custom properties with modular tokens, 3.5% fractal noise texture overlay, and fluid clamp() responsiveness.
- **Icons:** Lucide React (`lucide-react`)
- **Animations:** Motion (`motion`), CSS hardware-accelerated transforms, and comprehensive reduced-motion support (`data-motion="off"`).
- **Quality Gates:** Oxlint (Rust-powered linter)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
git clone https://github.com/MrhRafi3/mrh-rafi-portfolio.git
cd mrh-rafi-portfolio
npm install
```

### Development
```bash
npm run dev
```

### Production Build & Preview
```bash
npm run build
npm run preview
```
